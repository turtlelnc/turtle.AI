# 本地版本对齐记录

本次按用户选择接入独立 MLX 后端，保留已有 CPU 后端。架构和格式分别维护，
不会尝试把普通 Transformer 权重直接解释为 MoE/循环层/ELF 权重。

| 能力 | CPU 后端 | MLX 后端 |
|---|---|---|
| 文本模型 | 普通 Transformer、手写梯度 | MoE、循环层/ACT、自动微分 |
| 归一化 | LayerNorm，更新并保存参数 | RMSNorm，参数注册到优化器 |
| 注意力 | 因果注意力、正弦位置编码 | RoPE、窗口/稀疏注意力、KV cache |
| 多模态 | RGB 图像块和文本回答 | ELF 潜变量、可读取外部 T5 数据 |
| 优化器 | 裁剪 SGD | SNR 门控、GaLore、内存/SSD 状态 |
| 文件格式 | TRTLMODL，四个控制 Token | TRTLMX01 / GLR2 / ELF7，六个控制 Token |

接入时修复了以下具体问题：

- 全局线程分词缓存串用不同模型；旧 rank 缓存只按规则数量判断。
- 重复加载残留规则，失败加载会改变原分词器。
- 合并已存在关键字时可能复用/覆盖 Token ID；注册的特殊 Token 在训练时丢失，
  原保存格式也没有保存它们。
- 单文件长度不超过 400 字节时样本丢失，空数据会导致取模错误。
- macOS `sysctl` 和固定 GPU 选择使 Linux 无法运行；部分尺寸声称有 CLI 选项，
  实际没有读取。
- AR 只周期保存、没有最终保存；周期检查点步数会重复已完成的更新。
- 推理时缺失模型文件仍使用随机权重；损坏恢复可能混入部分加载参数。
- T5 文件缺少整体长度、Token ID 和有限值检查。

验证分为三个层次：分词器/数据回归，原 CPU 后端回归，以及真实 MLX CPU 小模型
训练、恢复和生成。MLX 运行时测试覆盖 packed batch、图编译、梯度累积、GaLore
刷新、SSD 状态、ELF/EMA 和合成 T5 文件。Apple Silicon / Metal 的结果需要
在实际 macOS 设备上补充；Linux CPU 测试不能代替 GPU 验证。

## 接下来优先做什么

1. **Apple Silicon 验证和数值对照。** 在 macOS 上执行相同测试；比较 packed
   batch/梯度累积、图编译开关、KV cache/完整前向的 logits 和梯度，而不只检查
   程序是否完成。对 SSD/常驻状态做更新值一致性检查。
2. **加入固定验证集与基线。** 固定数据切分，单独记录任务 loss、辅助 loss、
   专家溢出和吞吐/内存；对比普通优化器、SNR、GaLore，验证新增功能的实际收益。
   上传源码注释中的实验数字没有在本次独立复现，不能作为已验证结果。
3. **补齐完整训练状态恢复。** 保存两个 RNG 状态、GaLore 子空间年龄与刷新状态，
   明确学习率总步数，验证连续运行和中途恢复的更新一致性。
4. **如果目标是 T5/ELF 产品流程，先补编码与导出工具。** 接入真实 T5 编码器，
   生成训练潜变量及对应 unembedding；支持新提示词，不只评估既有记录。
5. **有稳定基线后拆分 main.cpp。** 按模型、优化器、推理和训练模块拆分，逐步
   移除全局运行时开关，并补参数配置序列化。
