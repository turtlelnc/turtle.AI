## 固定窗口验证

本次将验证扩大到 256 个窗口、32,768 个有效 Token，使用相同数据、种子 7、
上下文长度 128 和词表。第 620 步模型也在这批窗口上重新评估；不能直接将这里
的数字与上一轮只有 64 个窗口的结果作差。验证报告纯交叉熵，不包括训练中的
置信度惩罚或 MoE 辅助损失。

| 检查点 | 留出集交叉熵 | 困惑度 |
|---|---:|---:|
| 随机初始化 | 6.9424 | 1035.26 |
| 620 步，续训前 | 4.0712 | 58.63 |
| 901 步，中途快照 | 3.8985 | 49.33 |
| 1301 步，中途快照 | 3.6868 | 39.92 |
| 2000 步，续训后 | 3.5895 | 36.22 |

与同窗口的 620 步模型相比，最终交叉熵下降 11.83%，困惑度下降 38.22%。
本轮最初五个训练日志采样点的任务 loss 均值为 4.0939，最后五个为 3.5412。
训练 loss 的采样批次不同，前后质量判断以上表固定留出窗口为依据。

本次结果支持继续训练仍有收益，但只覆盖单个随机种子、连续选取的 Wikipedia
子集和一小部分留出文本，不能据此判断通用语言能力或完整语料上的泛化。
累计名义训练目标位置约 102.4 万，没有完成整个训练语料的遍历。

## 运行与生成

- 正确恢复源模型，并完成到第 2000 步；模型权重指纹发生变化。
- 原 620 步模型的步数、元数据和权重指纹保持不变。
- 训练、验证和生成日志没有出现 NaN/Inf。
- 三个固定提示词均正常生成 80 Token 并返回 END；关闭 KV cache 也正常完成。
- 数学提示词开启/关闭 KV cache 的这次生成文本相同，但这不是 logits 数值
  等价的证明，也没有覆盖长上下文或专家容量溢出的情形。
- 最终模型仍为 511,704 个 FP16 参数，检查点大小 7,164,718 字节。

生成仍有明显拼词和语义问题。例如 `The history of mathematics` 输出开头：

```text
 of the operely Geron in NC G Slabers, Sor and Wore Horlish.
(S Brers Divusa, Vanda Lavuk Diles Peft Manabs, Lued Hi
```

因此结论是训练链路稳定、留出集统计指标进一步改善，尚不能用于连贯回答。

## 复现

需要上一轮的 620 步模型及对应词表、相同的 Wikipedia 数据目录。仓库根目录执行：

```sh
python3 mlx/tools/train_wikipedia.py --resume-from build-mlx/wiki-small \
  --output build-mlx/wiki-continued --steps 2000 --resume-steps 0 --eval-samples 256
```

新输出目录必须不存在。工具会校验语料 SHA-256，复制模型和词表，验证目标步数
高于源检查点，然后执行续训前验证、训练、生成及最终验证。原实验不会被覆盖。
默认额外恢复测试仍是 20 步，本次传入 0 是因为续训本身已验证恢复流程。
原生训练器每 100 步保存；本次另外复制了 901 和 1301 步快照做只读中途验证。

本地产物不提交到 Git：

- `build-mlx/wiki-small/model.ckpt`：原 620 步模型。
- `build-mlx/wiki-continued/model.ckpt`：2000 步模型。
- `build-mlx/wiki-continued/tokenizer.bpe`：对应词表。
- `build-mlx/wiki-continued/summary.json`、`*.log`：主流程结果和完整日志。
- `intermediate.ckpt`、`late-intermediate.ckpt` 及对应摘要：两个中途快照。

模型训练使用代码提交 `4a55049`；本次续训参数入口和记录在后续提交。
扩大 `--steps` 改变了余弦学习率计划；恢复时 RNG 未保存，所以这不是从零连续
运行 2000 步的等价实验。GaLore 关闭，此次也未验证其子空间恢复轨迹。

## 后续优先项

继续长训前，补齐因果性、完整前向/KV cache 的 logits 对照，以及真实隐层的
专家分派和容量丢弃指标；再扩大验证覆盖并检查连贯性和任务表现。完整 RNG
状态恢复也需要补齐。Metal 仍需在 Apple Silicon 设备上验证，Linux CPU
结果不能替代它。
