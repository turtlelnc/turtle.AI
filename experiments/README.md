# Native memory research records

`results/` archives synthetic experiment metrics, including exploratory failures
and paired controls. `manifest.json` records file sizes and SHA-256 hashes.
README.md at the repository root documents protocols, caveats and reproduction.
Absolute workspace paths in the JSONs record original provenance; adapt them when
reproducing. Aborted incomplete raw-bias trials are excluded.

Binary model/probe checkpoints, page caches, Python environments and scratch data
remain outside Git. Results are not evidence of real-document quality or universal
rank-inversion suppression. Probe-reader scores are distinct from native LM scores.
